# GPX保存とGoogle Driveの設定

## 手動GPX保存

「今日のGPXをDriveへ書き出す」「昨日のGPXをDriveへ書き出す」は、Androidの保存先選択画面を開きます。端末内または保存先プロバイダーとして利用できるGoogle Driveを選べます。この経路ではアプリ独自のDrive API認可を使用しません。

1. Pixel Watch / FitbitでGPSルート付きのウォーキングを記録し、Health Connectに同期する。
2. アプリで運動・獲得標高の読み取りを許可する。
3. 対象日のGPX書き出しボタンを押す。
4. 運動ルートの読み取り同意が必要なら、表示された画面で許可する。
5. 保存先を選び、`walking-YYYY-MM-DD.gpx` を保存する。

## 毎日の自動バックアップ

この経路はDrive APIを使います。Google Cloud Consoleで以下を設定してください。

1. Google Cloudプロジェクトを作成し、Google Drive APIを有効にする。
2. OAuth同意画面を設定する。
3. Android用OAuthクライアントを作成する。パッケージ名は `com.elevation`、SHA-1は使用するアプリ署名の値に合わせる。
4. テスト中は必要に応じてOAuthテストユーザーにGoogleアカウントを追加する。
5. アプリで自動バックアップをONにし、アカウント選択とDrive認可を完了する。キャンセルした場合はONにならない。

利用するスコープは `https://www.googleapis.com/auth/drive.file` です。GPXには位置・時刻・高度が含まれ、Google Driveへ送信されます。

JobSchedulerで毎日02:30以降に前日分を保存します。省電力制御やネットワーク状態で実行が遅れることがあります。再起動時はBootCompletedReceiverで再スケジュールします。

## 制限

Health Connectのバックグラウンド読み取り権限や、他アプリが作成したルートへの同意が必要になる場合があります。現在の自動バックアップはこれらの条件で失敗する可能性があり、アプリに表示される最終状態を確認してください。ルート同意が必要な場合は、アプリを開いて対象日のGPXを手動で書き出してください。

同じ日の自動保存成功後は再実行をスキップします。部分的なルート取得と後から到着する記録の再保存は、今後の検証項目です。
