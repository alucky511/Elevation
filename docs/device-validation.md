# Pixel端末での表示確認

対象実機: Pixel 10a / Pixel Watch 4。実機確認は未実施です。

## 実装
- スマホはホーム（標高、Watchへの送信）と保存・設定（GPX、自動バックアップ、権限）を分離。
- 画面表示をMobileDashboardViewへ切り出し、既存の読み込み・送信処理を維持。
- システムバーとカメラ領域のinsetsを反映。説明文・ボタンは可変高さで折り返し、全体をスクロール。
- 山と上向き矢印は108dpベクターの中心66dp円内に収める。カラーと単色版を両アプリで統一。

## 自動確認
Android 35エミュレーター上で320/412/760dp幅 × フォント倍率1.0/1.3/2.0 × 両ページを測定し、文字の切れ・省略とボタンの高さを確認。実際のビューからPNGを生成し、Actionsのelevation-ui-previewsへ保存します。
これは端末固有のランチャーや画面構成を再現する実機試験ではありません。

## 実機で確認する項目
1. 同じActions実行のmobile/wear APKを各端末にインストール。
2. Pixel 10aで標準/最大文字サイズ、縦/横、ジェスチャー/3ボタン操作時に表示とスクロールを確認。
3. 権限許可→更新→Watch再送→GPX保存の操作を確認。
4. Pixel Watch 4のアプリ一覧で山・矢印の欠けや偏りを確認。テーマアイコンも確認。
5. 大きな標高値、記録なし、未接続、権限なしの表示を確認。

Android公式のinsets説明: https://developer.android.com/develop/ui/views/layout/edge-to-edge
